# ADR-0003: 혼합 샘플링 (상위 사용자 이벤트 단위 + 나머지 겹치는 사용자 해시)

- 날짜: 2026-10-16 / 상태: 채택

## 비교 (sim/compare_sampling.py, 1분 조회 6만 건, 긴 꼬리 사용자 분포)
| 통과 비율 | 이벤트 무작위 (오차 / 퍼널 왜곡) | 사용자 해시 | 혼합 |
| --- | --- | --- | --- |
| 50% | 0.8% / +2.8%p | 4.9% / +0.0%p | 1.5% / +0.0%p |
| 10% | 2.3% / +9.8%p | 7.6% / +0.3%p | 5.6% / +0.0%p |
| 2% | 5.5% / +15.8%p | 18.2% / +1.1%p | 5.4% / -0.5%p |

## 결정
- 혼합 방식 채택. 상위 사용자 판별은 Count-Min Sketch (sampling/heavy.py)
- 겹치는 임계값(hash < rate)으로 비율이 바뀌어도 세션 유지
- 남긴 이벤트마다 비율을 실어 1/비율로 집계

## 영향
1분 단위 2% 오차 목표는 낮은 비율에서 불가능 → H2를 '표시한 오차 범위의 적중률'로 변경

## 실제 데이터 확인 (2026-10-18, ADR-0010)
- 위 표는 가정한 분포의 결과다. 실제 11월 데이터에서는 상위 사용자 처리 이득이 작다
- 퍼널 왜곡은 세션이 남을 확률로 가중하면 어느 방식이든 1%p 안팎. 상위 사용자 기준은 ADR-0010으로 바꿈
