# ADR-0004: Kafka 파티션 키는 user_id, 상품·카테고리 집계는 2단계

- 날짜: 2026-10-16 / 상태: 채택

| 기준 | 장점 | 단점 |
| --- | --- | --- |
| user_id (채택) | 세션 순서 유지, 고른 분산, 사용자 해시 샘플링과 일치 | 상품별 집계는 다시 모아야 함 |
| product_id | 상품 집계가 쉬움 | 타임딜 상품 하나로 특정 파티션 과부하 |
| 무작위 | 가장 고른 분산 | 세션 순서 깨짐 |

상품·카테고리 집계는 (키, 소금 0~7)로 부분 합계 → 소금을 떼고 최종 합계 (flink_jobs/main_job.py).
